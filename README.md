## Film Frontend

A web application built for movie enthusiasts to discover films, share reviews, and connect through community discussions, fan art, and AMA sessions.

### Core Functions

Movie Discovery & Reviews: Browse the movie catalog and new releases, view detailed movie pages with streaming platform availability (Netflix, Prime Video), and submit ratings and written reviews.

Community Discussions: Create topics and participate in threaded discussions with other film fans.

Fan Art Gallery: Share and browse community-created fan art.

AMA Sessions: Join and interact in Ask Me Anything threads.

Inbox: View notifications and messages directly within the platform.

User Accounts & Profiles: Full authentication flow including registration, login, OTP verification, password recovery/reset, and personal user profiles.

Admin & Moderation: Dedicated admin dashboard for managing users and moderating platform content with documented removal reasons.
